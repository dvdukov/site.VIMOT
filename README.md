# Mebel Vimot — тап-линк

Одностраничный переходник (в духе Linktree) для мебельной компании Mebel Vimot:
соцсети, прямой контакт, каталог/портфолио и галерея работ по разделам. Обычный
статический сайт — HTML/CSS/JS без сборщиков.

**Сайт:** https://dvdukov.github.io/site.VIMOT/
(адрес изменится на `https://mebelvimot.github.io/site.VIMOT/`, когда будет переименован
аккаунт GitHub на `MebelVimot`)

## Структура

```
index.html            главная страница
portfolio.html         страница с PDF-каталогом (запасной вариант просмотра)
assets/
  logo/                логотип (logo.svg — основной, logo-cyrillic.svg — кириллический вариант)
  fonts/                фирменные шрифты (Playfair Display, Mirra)
  icons/                svg-иконки соцсетей и кнопок
  images/gallery/       фото работ, по папкам-разделам:
    kitchens/             Кухни
    wardrobes/            Гардеробные
    cabinets/              Шкафы
    bathrooms/             Санузлы
  portfolio/
    portfolio.pdf        актуальный PDF-каталог
css/
  variables.css          цвета, шрифты, @font-face — фирменный стиль в одном месте
  style.css               вёрстка
  animations.css           анимации
js/
  config.js                контент: тексты, ссылки, разделы галереи — редактируется здесь
  main.js                    рендер страницы, вкладки галереи, лайтбокс, анимации
```

## Как поменять контент

Всё редактируется в **`js/config.js`**, вёрстку трогать не нужно:

- **Ссылки/кнопки** — массив `links`. Чтобы поменять адрес VK/Instagram/Telegram/прямого
  контакта — меняете `href`. Чтобы добавить новую кнопку — добавляете объект с `id`,
  `label`, `href`, `icon` (доступные иконки: `vk`, `instagram`, `telegram`, `message`,
  `globe`, `catalog`).
- **Кнопка "Основной сайт"** — сейчас `disabled: true` с бейджем "скоро". Как только сайт
  будет готов — уберите `disabled: true` и `badge`, впишите `href`.
- **Тексты о компании и преимущества** — объект `company`.
- **Разделы галереи** — массив `categories` (id должен совпадать с названием папки в
  `assets/images/gallery/`). Чтобы добавить новый раздел — создайте папку и добавьте
  объект `{ id, label }` в массив.

## Как добавить фото в галерею (без правки кода)

Список фото в каждой вкладке подтягивается автоматически прямо из репозитория при
каждом открытии сайта — **никакой код редактировать не нужно**, файл сам появится на
сайте, как только окажется в нужной папке.

**С телефона или компьютера — через сайт GitHub:**
1. Откройте нужную папку в браузере:
   - Кухни — `github.com/<владелец>/<репозиторий>/tree/main/assets/images/gallery/kitchens`
   - Гардеробные — `.../wardrobes`
   - Шкафы — `.../cabinets`
   - Санузлы — `.../bathrooms`
2. **Add file → Upload files** → выберите фото (можно сразу несколько) → **Commit changes**.
3. Готово — имя файла не важно, переименовывать не нужно. Фото появится на сайте почти
   сразу (список кэшируется в браузере посетителя на 5 минут).

**С компьютера через git** (если репозиторий уже склонирован):
```
git add assets/images/gallery/<раздел>/
git commit -m "Добавить фото"
git push
```

## Как обновить каталог (PDF)

Просто замените файл `assets/portfolio/portfolio.pdf` на новый — **с тем же именем**,
ничего больше менять не нужно.

## Как поменять логотип/цвета/шрифты

- Логотип: замените `assets/logo/logo.svg`.
- Цвета: переменные `--color-*` в `css/variables.css`.
- Шрифты: файлы в `assets/fonts/` + правила `@font-face` в начале `css/variables.css`.

## Как проверить локально

Галерея загружает список фото через GitHub API (`fetch`), а браузеры блокируют такие
запросы для страниц, открытых напрямую с диска (`file://`). Поэтому для локальной проверки
нужен любой простейший локальный сервер, например:

```
npx serve .
```

и открыть адрес, который он покажет (обычно `http://localhost:3000`). Остальные страницы
(вёрстка, тексты, ссылки) можно смотреть и просто двойным кликом по `index.html` —
не заработает только сама галерея.

## Деплой на GitHub Pages (бесплатно)

1. Создайте пустой публичный репозиторий на [github.com/new](https://github.com/new).
2. В этой папке:
   ```
   git init
   git add .
   git commit -m "Первая версия тап-линка"
   git branch -M main
   git remote add origin <ссылка на ваш репозиторий>
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Source: Deploy from branch → main / (root)**.
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://<ваш-username>.github.io/<название-репозитория>/`.
5. Любое следующее обновление — просто `git add . && git commit -m "..." && git push`.
